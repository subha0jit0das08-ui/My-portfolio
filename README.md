# My Portfolio & Frontend Web Projects

A collection of responsive frontend web pages, user authentication flows, and portfolio templates built with vanilla **HTML5**, **CSS3**, and **JavaScript**.

##  Repository Structure

```text
portfolio/
├── home.html               # Main portfolio landing page
├── home.css                # Styling, layout, and animations for the portfolio
├── home.js                 # Interactive UI scripts and dynamic behavior
├── background.jpg          # Main background visual asset
└── full front/             # Complete multi-page frontend authentication & UI kit
    ├── home.html & home.css         . Homepage with navigation, cards & marquee showcase
    ├── login.html & login.css       . User login interface with glassmorphism styling
    ├── register.html & register.css . Account registration form
    ├── forgot.html & forgot.css     . Password recovery page
    ├── privecy.html & privecy.css   . Privacy policy page
    ├── terms.html                   . Terms and conditions page
    ├── logo.png                     . Custom site logo
    ├── mountain.jpg                 . Full-screen background wallpaper
    └── ui1.jpeg – ui7.jpeg          . UI showcase & gallery card images
```

 ## Key Features

Personal Portfolio (portfolio/): Clean landing page featuring custom CSS layouts and JavaScript interactivity.
 Authentication Flow (full front/): Complete set of linked frontend screens including Login, Registration, and Forgot Password pages.
  Legal & Info Pages: Dedicated Privacy Policy and Terms of Service templates.
  Modern UI Styling: Built from scratch using Flexbox, CSS animations, custom form controls,
 and responsive media assets without external CSS frameworks.
